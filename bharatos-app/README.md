# BharatOS Frontend

Source directory for the BharatOS browser-based desktop application.

## Stack
- **React 18**
- **TypeScript**
- **Vite 5**
- **Tailwind CSS v4**
- **Zustand**
- **IndexedDB (`idb`)**
- **Lucide React**

## Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
The build outputs to `../public/` for deployment.
